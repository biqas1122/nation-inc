Background music (original, generated by tools/make_music.py — no copyright claims possible).

One track is picked for each video and mixed under the voice (quiet while the narrator talks,
a little louder in pauses). Volumes are set by music_volume / music_duck_volume in config.json.

You can add your own tracks here too (.mp3 / .m4a / .wav), e.g. from YouTube Studio → Audio Library
("Attribution not required"). Delete a file to stop it being used.
